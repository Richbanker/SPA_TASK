# Task Manager SPA


[![Просмотры README](https://vbr.nathanchung.dev/badge?page_id=Richbanker.SPA_TASK&text=README_Views)](https://github.com/Richbanker/SPA_TASK)

## Описание

Одностраничное приложение для управления списком задач с использованием React, Redux Toolkit, TypeScript и styled-components.

## Запуск

1. Установите зависимости:
   ```
   npm install
   ```
2. Запустите приложение:
   ```
   npm start
   ```

## Функционал

- Создание, редактирование, удаление задач.
- Приоритеты задач (низкий, средний, высокий).
- Сортировка по дате создания и приоритету.
- Стилизация через styled-components.
- Хранение задач в Redux Store.

## Стек

- React + Redux Toolkit + TypeScript
- styled-components
